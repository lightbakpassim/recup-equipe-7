## Ouvrir le prototype

Double-cliquer `prototype/index.html`  
**ou** dans ce dossier :

```bash
python -m http.server 8765
```

Puis ouvrir [http://localhost:8765/prototype/](http://localhost:8765/prototype/)

## Parcours de démo (2–3 min)

1. Accueil → carte **Badge étudiant**
2. **C’est à moi**
3. RDV **BU, 14h** → confirmer
4. Écran **C’est récupéré**
5. Bonus (si le temps) : Fil → onglet **Prêt** → calculatrice

## Script oral (~8 min)

**0:00** — On est l’EQUIPE_7 : Light, Ami Raphaëlla et Godwin. On présente Récup’. Le tableau du campus pour retrouver ce qu’on a perdu, et emprunter ce qu’il nous manque.  
**0:20** — Lundi, 12h10. Lina sort de l’amphi : plus de badge. WhatsApp, 40 messages, rien. Karim a trouvé le badge à la cafet, il le met dans son sac. Le soir, Lina paie un duplicata. Le problème n’est pas « on perd des objets ». C’est qu’il n’existe pas d’endroit simple pour relier celui qui perd et celui qui trouve.  
**1:10** — Ça concerne tout le monde, tous les jours. WhatsApp n’est pas fait pour ça. L’accueil existe, mais on n’y va pas entre deux cours.  
**1:40** — Récup’ : trois gestes. Trouvé, Perdu, Prêt. On publie en 30 secondes. RDV à la BU. On clôture.  
**2:30** — Cinq fonctions, pas quinze. Publier, chercher, prêter, dire « c’est à moi », marquer « récupéré ».  
**3:15** — Voici le proto. On vous montre Lina et Karim.  
**3:30–6:00** — Démo (parcours ci-dessus).  
**6:00** — Valeur : temps, argent, entraide. Si on est retenus : alertes, carte des lieux, lien accueil.  
**6:40** — Un problème vécu. Une phrase. Un proto. Merci.
